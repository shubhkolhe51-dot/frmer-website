# 🌾 Krishi Mitra (महाराष्ट्र कृषी मित्र मंच)

An AI-powered agricultural advisory portal for farmers in Maharashtra.

## 🚀 Live Demo & GitHub Pages Hosting
- **GitHub Pages Link**: `https://<your-username>.github.io/<your-repository-name>/`
- **Features**:
  - ⛅ **Real-Time Village Weather & Climate Advisory** (Google Weather & Open-Meteo GFS/ECMWF Aligned)
  - 🧅 **Multi-Source Mandi Market Prices** (Agmarknet, MSAMB & APMC Direct Auction Feeds)
  - 📰 **Real-Time Agri News & Export/Import Duties**
  - 🌾 **Multi-Crop Isolated Field Logbooks** (Watering counts, Pesticides, Labor Wages & Costs)
  - 🤖 **AI Crop Leaf Doctor** (Pest & Disease Diagnosis with Spray Recommendations)
  - 📞 **Farmer Support Helplines**

## 💻 Tech Stack
- **Frontend**: HTML5, Modern Vanilla JS, Tailwind CSS, Material Symbols
- **Backend**: FastAPI (Python 3.14), Uvicorn
- **AI Engine**: Gemini AI Vision API
- **Deployment**: GitHub Pages (Client-Side SPA) + FastAPI / Cloudflare Tunnel
